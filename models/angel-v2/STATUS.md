## Gotchas
- glTF import -> quaternion rotation; set `rotation_mode='XYZ'` before rotating.
- Cycles bake returns black if denoising is on (no OIDN in apt Blender).
- apt Blender 3.4 needs `apt-get update` + `libegl1 libgl1` for rendering.
- Tripo `face_limit`/`smart_low_poly` exist if regenerating.
- Blender's Decimate opened holes on these meshes; use weld-first + fast-simplification.
