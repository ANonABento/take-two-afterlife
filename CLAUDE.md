# Take Two: Afterlife — agent notes

UE 5.5 C++ party game (Epic AI MegaJam 2026). `plan.md` is the source of truth for design and task handoffs; read the relevant handoff before touching a system.

## Layout
- `Core/` — engine-free C++17 rules (state machine, placement/budget, traps, scoring, replay, edit list, ratings, bots). CMake + vendored doctest. Put logic here first and test it with doctest.
- `Source/TakeTwoAfterlife` — UE game module. Core is compiled through one-line wrapper `.cpp`s in `Private/CoreLib` (plus `Source/TTACore/Private`). **Every new `Core/src/*.cpp` needs a wrapper**, or UE fails to link (`test_bots.py` checks this).
- `Scripts/` — UE editor Python (content/map builders, run through `UnrealEditor-Cmd -run=pythonscript`) plus engine-free helpers. `Scripts/tests/` = unittest suite with a mocked `unreal` module and static checks on C++ source (IWYU includes, exported members, UE 5.5 APIs, config).
- `Content/` — generated by `Scripts/setup_content.ps1`; edit the layout/spec scripts, then rebuild, instead of hand-editing maps.

## Commands
- Tests: `powershell -File Scripts/test.ps1` (no make on this PC) or `make test`. Deps: `python -m pip install -r Scripts/requirements.txt`. Use `python`, not `python3` (Windows Store stub).
- UE editor build: `& "C:\Program Files\Epic Games\UE_5.5\Engine\Build\BatchFiles\Build.bat" TakeTwoAfterlifeEditor Win64 Development -Project="$PWD\TakeTwoAfterlife.uproject" -WaitMutex`
- Automation (in-editor): `Automation RunTests TTA.`

## Gotchas
- `EngineAssociation` must stay `"5.5"` (a test enforces it). The editor sometimes rewrites it to a GUID; revert that before committing.
- `DefaultPlatformService=NULL` until EOS Artifact IDs exist; never commit the EOS ClientSecret.
- `tripo.txt` holds a local API token and is gitignored. Keep it out of commits. AI-generated assets (Tripo, etc.) are allowed but must be credited with their tool in CREDITS.md.
- Unreal changes can't be verified by the Python tests alone. Say what still needs an editor compile or Automation run.
- Each task appends a DEVLOG.md entry and a plan.md handoff (Done / Left / Surprises).
